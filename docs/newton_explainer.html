뉴턴-랩슨 vs 경사하강 — 포트폴리오 최적화 해설

원자재 대시보드의 ⑤ 포트폴리오 탭에서 쓰는 최적화가 어떤 방식인지, 변수가 3개 이상일 때 어떻게 되는지, 경사하강과 무엇이 다른지를 직접 움직여 보며 확인하는 페이지입니다. (이 파일 하나로 열리며 인터넷이 필요 없습니다.)

먼저 결론 3줄
  1. "μ와 MinVar 두 개 사이의 조합"은 변수 개수와 상관이 없습니다. 평균-분산은 품목 N개 비중 w 전체(N차원 벡터)를 한 번에 푸는 문제입니다. 모멘텀·칼만 페어 같은 신호는 변수로 늘어나는 것이 아니라 기대수익 μ를 만드는 재료입니다. 위험회피계수 λ가 μ를 얼마나 믿을지(MinVar ↔ 순수 수익 추구)를 정합니다.
  2. 우리 코드의 Newton은 '바스켓 포트폴리오' 계산에 씁니다(portfolio.py의 newton_mv, newton_risk_parity). Portfolio Customization에서 전략 3개 이상을 섞을 때는 Newton이 아니라 직접·동일·역변동성·최소분산(SLSQP)·Sharpe 비례 방식으로 전략 비중을 정합니다(app.py의 _combine).
  3. 경사하강은 기울기만, 뉴턴은 기울기 + 곡률(헤시안)을 씁니다. 위험 행렬 Σ가 비뚤어져 있을수록(상관이 높을수록) 경사하강은 지그재그로 느려지고, 뉴턴은 곡률로 보정해 몇 번 만에 도착합니다.

① 평균-분산 문제를 N차원으로 보기

한 시점의 목표는 아래와 같습니다. w는 N개 품목의 비중, μ는 기대수익 벡터, Σ는 공분산 행렬입니다.

maxw   μ′w − (λ/2)·w′Σw − Σi ci·|wi − wi0|   (Σw = 1, w ≥ 0)

제약이 없다면 정답은 한 줄입니다: w* = (1/λ)·Σ−1μ. 여기서 λ가 커지면 μ의 영향이 작아져 최소분산(MinVar)에 가까워지고, λ가 작으면 μ가 큰 품목에 몰립니다. 합이 1이라는 제약 아래에서는 이 해가 "MinVar 포트폴리오 + μ를 반영한 투기 포트폴리오"의 두 덩어리 조합이 되는데(Two-Fund), 이것이 "두 개 사이의 조합"이라는 기억의 출처입니다. 품목이 3개든 19개든, 신호가 하나든 다섯이든 같은 식입니다.

신호가 여러 개일 때 (모멘텀 + 칼만 페어 + 가치 …)

  • 방법 A. 신호를 μ에 합치기: μ = Σk θk·(신호 k의 기대수익 환산). 변수는 여전히 w (N개). 우리 바스켓 탭이 이 방식입니다(모멘텀 신호 IC로 μ 환산).
  • 방법 B. 전략을 자산처럼 다루기: 전략 K개의 수익률을 "자산 K개"로 보고, 전략 비중 K개를 같은 평균-분산으로 푸는 것. Portfolio Customization이 이쪽인데, 최적화 대신 단순 규칙(동일·역변동성·MinVar·Sharpe 비례)을 씁니다. 전략 수익률의 μ 추정이 불안정하기 때문입니다.

참고: 변수가 늘면 Σ가 N×N으로 커지고 추정 오차가 폭발합니다. 이 때문에 우리 코드는 모든 곳에서 Ledoit-Wolf 수축 공분산을 씁니다(표본 공분산 S를 단순한 목표 행렬 F 쪽으로 δ만큼 당겨 줌, Σ̂ = δF + (1−δ)S, 평균 δ ≈ 0.16).

② 경사하강 vs 뉴턴 — 직접 움직여 보기

두 자산의 "위험" 곡면입니다(타원 모양 등고선, 가운데가 최적점). 상관이 높을수록 타원이 길쭉해집니다(조건수 κ가 커짐). 경사하강은 가장 가파른 방향으로 일정 보폭씩, 뉴턴은 곡면의 곡률을 반영한 방향으로 갑니다. 캔버스를 클릭하면 출발점이 바뀝니다.

읽는 법. 왼쪽: 주황 점선=경사하강 경로, 파랑 실선=뉴턴 경로. 오른쪽: 반복마다 남은 오차(로그). 뉴턴은 직선에 가깝게 떨어지고, 경사하강은 κ가 클수록 완만하게 줄어듭니다. 보폭을 2/L 근처로 키우면 경사하강이 발산합니다. 비선형 정도를 올리면 뉴턴도 한 번에 끝나지 않고 몇 번 반복합니다(이차식일 때만 1번).

두 방법의 한 줄 차이

경사하강:   xk+1 = xk − α·∇f(xk)      뉴턴:   xk+1 = xk − [∇²f(xk)]−1·∇f(xk)

Ridge·Lasso·LSTM 같은 모델 학습에는 변수가 많아 경사하강류(Adam 등)를 씁니다. 포트폴리오 비중은 변수가 19개 안팎이라 뉴턴이 훨씬 정확하고 빠릅니다.

③ 제약(합 100%, 롱온리)은 어떻게 푸나 — 배리어 + 뉴턴

"w ≥ 0"을 그대로 두면 뉴턴을 쓸 수 없어서, 경계에 가까울수록 값이 −∞로 떨어지는 로그 배리어 τ·Σlog wi를 목적함수에 더합니다. τ를 크게 시작해 점점 줄이면(1e-3 → 1e-12) 해가 경계(0 비중)까지 부드럽게 따라갑니다. "합 = 1"은 KKT 연립방정식에 한 줄을 더해 매 반복 지킵니다(우리 newton_mv가 이 방식, 내부점법).

1차원 예시: 품목 하나의 비중 w를 0~1 사이에서 정합니다(나머지 비중은 변동성이 다른 다른 품목). μ가 작거나 음수면 배리어 없는 해가 w<0(공매도)이지만 롱온리에서는 0 쪽 경계로 밀립니다.

④ 3개 품목으로 직접 풀어 보기 (Newton, 롱온리)

대두·구리·금처럼 3개 품목을 가정하고, 실제 코드와 같은 방식(배리어 + 등식제약 KKT 뉴턴)을 이 페이지 안에서 계산합니다. 품목이 늘어도 방식은 같고 행렬 크기만 커집니다.

변동성은 대두 20%, 구리 25%, 금 15%로 고정했습니다. 막대는 위에서부터 평균-분산(Newton), MinVar(μ를 안 믿는 극단), 리스크 패리티(μ를 안 쓰고 위험기여만 균등)입니다. 오른쪽은 λ를 바꿔 가며 그린 위험-수익 곡선(효율적 투자선)이고 점이 현재 λ입니다. μ를 조금만 바꿔도 평균-분산 비중이 크게 흔들리는데, 이것이 원자재처럼 예측력이 약한 자산에서 리스크 패리티가 실전에 강한 이유입니다.
