LangGraph 4계층 흐름 — 수치 · 전문가 의견 · 온톨로지 · LLM 인터페이스

llm/graph.py의 실제 그래프에서 그린 그림. 상자를 누르면 설명. 점선 = 조건 분기. 인터넷 없이 열림 · 대시보드/발표에는 미반영(향후 계획).

① 수치② 전문가 의견③ 온톨로지④ LLM 인터페이스사람 확인분류

상자를 눌러 보세요

  • 숫자는 ① ② ③ 도구만 만들고, ④ LLM은 문장으로 엮기만 함
  • verify가 답변 숫자를 사실 목록과 대조 → 틀리면 다시 쓰게 함(최대 2회)
  • 의견 기록은 사람 확인(approve_view) 후에만 저장
  • 로컬 Ollama(127.0.0.1)만 · LangSmith 추적 끔
실행
.venv\Scripts\python.exe -m llm.graph "대두박 지금 살까?"
Mermaid 원문 (docs/LLM_graph.mmd와 같음)

	finish(finish)
	fallback(fallback)
	extract_view(extract_view)
	approve_view(approve_view)
	save_view(save_view)
	check_data(check_data)
	approve_refresh(approve_refresh)
	run_refresh(run_refresh)
	__end__([<p>__end__</p>]):::last
	__start__ --> classify;
	approve_refresh --> run_refresh;
	approve_view --> save_view;
	check_data --> approve_refresh;
	classify -.-> check_data;
	classify -.-> extract_view;
	classify -.-> numeric;
	compose --> verify;
	expert --> ontology;
	extract_view --> approve_view;
	numeric --> expert;
	ontology --> compose;
	verify -.-> compose;
	verify -.-> fallback;
	verify -.-> finish;
	fallback --> __end__;
	finish --> __end__;
	run_refresh --> __end__;
	save_view --> __end__;
