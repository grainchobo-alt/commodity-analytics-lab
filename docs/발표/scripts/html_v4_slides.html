데이터는 두 방향으로 읽음 — 시계열과 횡단면

같은 표라도 '한 품목의 시간 흐름'으로 보느냐, '같은 날 품목끼리 비교'로 보느냐에 따라 질문이 달라짐

시계열 (가로로 읽기)

한 품목의 가격이 시간에 따라 어떻게 변하나
  • 질문: 다음 달 옥수수는 오를까?
  • 쓰임: 위험 크기 예측, 추세 판단

횡단면 (세로로 읽기)

같은 시점에 어느 품목이 상대적으로 싼가
  • 질문: 이번 달 무엇부터 살까?
  • 쓰임: 품목 순위, 비슷한 품목 묶기
칸에 마우스를 올리면 품목·월·수익률 표시. 버튼으로 시계열 줄 / 횡단면 열을 강조.
자료: 원자재 12개 월간 수익률(%, 롤 보정), 최근 12개월(마지막 달은 기준일까지). 3D 막대 높이는 ±20%에서 자름, 숫자는 실제 값.
Ⅲ

효율적 투자선 — 연도별로 움직여 보기

효율적 투자선 = 같은 위험에서 가장 높은 수익을 내는 조합들의 경계선. 해마다 직전 5년 자료로 다시 그림

우리 혼합 (★) 경계선과 차이 그해 사후 최적 (●) 최적 비중
  • 회색 선 = 지난 연도들의 경계선 → 경계가 해마다 움직임
  • 2011–14 · 2024–26: ★가 경계선 위 (차이 0–0.4%p)
  • 2015–20: 한 전략 독주(모멘텀 → 가치) → 사후 최적은 '몰빵', ★는 연 3–4%p 낮음
  • ● 위치는 해마다 크게 이동 → 미리 알 수 없음. 고정 혼합은 최선은 아니어도 꾸준히 경계선 근처
▶ 재생 또는 슬라이더로 연도 이동 · 점에 마우스
3대 전략 각 목표 변동성 10%, 주간 수익률, 연도별 직전 5년 평균·공분산으로 조합 6,000개 계산. 차이 = 우리 혼합과 같은 위험 이하 조합 중 최고 수익 − 혼합 수익.
Ⅳ

지금 바로 쓰는 기능 — '지금 살까, 미룰까' 주간 판단

두 가지를 매주 계산: 지금 가격이 매력적인가(점수) · 기다리면 더 싸질 가능성이 높은가(확률)

· 가격 매력 점
3년 범위 안 위치'더 쌀 확률' 사용

검증 (2017년 이후, 근거 확인 품목)

  • 판단 하나하나는 틀릴 수 있음 → 매주 반복할수록 평균 우위 누적
  • 옥수수 카고(3만 톤) 매주 판단 시 연 약 $35만 절감 기대(예시)
판단 값은 기준일 앱 화면 값(발표 전 갱신 필요). 가격 = 최근 3년 주간 연속월물(롤 보정 전). 검증 = 2008–2016으로 정한 규칙을 2017년 이후에 그대로 적용, 25개 품목 중 근거 확인 9개.
상세

공통 흐름으로 요약 (PCA) — 실제 옥수수·대두·밀

점 하나 = 한 주의 세 품목 수익률(표준화). 빨간 축 = 가장 넓게 퍼진 방향 = '곡물 공통 흐름'

읽는 법

  • 점들이 빨간 축을 따라 길쭉하게 퍼짐 = 세 품목이 대부분 함께 움직임
  • 첫 흐름이 전체 움직임의 설명
  • 축에서 멀리 떨어진 점 = 한 품목만 따로 움직인 주(작황·정책 등 개별 뉴스)
  • 드래그로 회전, 점에 마우스 → 날짜 표시
자료: 주간 로그 수익률 2007–현재, 품목별 표준화(±4에서 자름). PCA = 공분산 행렬의 첫 고유벡터.
상세

위험 크기 예측 (GARCH) — 품목 × 시간 지형

높이·색 = 그달 예측한 연 변동성(%). 위기 때 여러 품목이 동시에 솟음

읽는 법

  • 2008·2020·2022에 산맥처럼 함께 솟음 = 위험은 몰려서 옴
  • 원유는 다른 품목보다 봉우리가 높고 뾰족
  • 방향은 못 맞혀도 '얼마나 출렁일지'는 예측됨 → 포지션 크기·VaR에 사용
  • 드래그로 회전 · 마우스로 값 확인
자료: 주간 수익률로 품목별 GARCH(1,1)·t분포 추정, 조건부 변동성 × √52, 월평균(90%에서 자름).
상세

시장 국면 판별 (HMM) — 지금 위기일 확률

원자재 동일 비중 주간 수익률로 '평시·위기' 2개 국면을 추정. 빨간 면 = 위기 확률

읽는 법

  • 위기 확률이 높은 해:
  • 아래 막대를 끌어 기간 확대 · 마우스로 날짜별 확률
  • 위기 국면 = 변동성 크고 품목 간 상관 상승 → 분산 효과 약화, 포지션 축소 판단에 참고
자료: 2-상태 Gaussian HMM(hmmlearn), 2006–현재 주간. 표시값은 전체 표본 평활 확률(설명용) — 실시간 판단에는 그날까지 자료만 쓰는 필터 확률 사용.
