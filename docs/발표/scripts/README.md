# 발표 자료 생성 스크립트

`원자재_퀀트_MI_발표_v*.pptx`를 다시 만드는 스크립트. 산출물(pptx·이미지·중간 json)은 git 제외.

| 파일 | 역할 |
|---|---|
| `charts.py` | 실제 데이터·개념 예시 차트 PNG → `img/`, 수치 → `nums.json` |
| `charts3d.py` | 3D 상관 지형·3D 효율적 투자선 PNG |
| `charts_v2.py` | v2 추가 차트: 횡단면 vs 시계열, 랜덤워크, 몬테카를로(브라운 운동) |
| `charts_v3.py` | v3 추가 3D 차트: 머신러닝 예측 지형, 위험 크기 지형, 연도별 효율적 투자선 |
| `charts_v4.py` | v4 차트: 퀀트 학문 지도(정밀판), AI 카드별 3D 8개(실제: PCA·FinBERT·GARCH·HMM), 연도별 효율적 투자선 4×4 + 3D 리본 |
| `deck_v{N}.js` | pptxgenjs로 슬라이드 조립 (`data.json`, `img/`, `notes_v{N}.js` 사용) |
| `deck_v4_glass.js` | 유리판 PPT: deck_v4.js를 그대로 실행하며 pptxgenjs를 감싸 배경(흐르는 색 그라데이션 그림)·반투명 카드·그림 액자·세리프 제목만 바꿈 → `build.py v4 --glass` |
| `build.py` | 위 단계를 순서대로 한 번에 실행 + `data.json` 생성 |
| `notes_v{N}.js` | 장별 발표자 노트(장 순서와 1:1, 개수가 다르면 경고). v4부터 `[초, 대본]` → `build.py`가 `docs/발표/발표대본_v{N}.md`(시간 배분표 + 대본)도 생성 |

## 버전
| 버전 | 대상 | 분량 | 특징 |
|---|---|---|---|
| v1 | 임원 보고(상세) | 46장 | 모델별 개념 장표(GARCH·HMM·Kalman·VaR 등), ML 계열별 장표 |
| v2 | 임원 보고 10분 | 본문 13장 + 별첨 1장 | 비전공 청중 기준 — 기법 이름은 별첨으로, AI 모델 한 장, 시계열 vs 횡단면, 랜덤워크·몬테카를로, 3대 전략 장표 (※ 3장 가격 흐름 화살표가 반대 — v3에서 수정) |
| v3 | 임원 보고 약 12분 | 본문 17장 + 별첨 1장 | v2 + 퀀트 학문 지도, AI 모델 2장(3D), 멀티모달 흐름도, 3D 효율적 투자선, 가격 흐름 공급사→당사→고객사 (※ 13장 3D 투자선은 선이 겹쳐 '매년 경계선 가까이'로 과대 표현 — v4에서 수정) |
| v4 | 임원 보고 약 13분 | 본문 18장 + 별첨 2장 | v3 + 혼합 계산 장(옥수수 예시: 전략별 비중 × 50·25·25 → 순 비중), 퀀트 지도 정밀판(원마다 기법·겹치는 영역·바탕 수학, 오른쪽 쉬운 설명), AI 카드 8개마다 대응 3D 그림, 효율적 투자선 연도별 4×4(겹침 없음) + 3D 리본, 확장 비전 = 품목군(식량·철강·소재·에너지) + 품목별 분석 가능 여부(●◐✕, 별첨 2 판정표) |

새 버전은 `deck_v{N}.js`·`notes_v{N}.js`를 추가 (이전 버전 파일은 그대로 두어 언제든 다시 생성 가능).

## 실행 (프로젝트 루트에서) — 한 번에
```
.venv\Scripts\python.exe docs\발표\scripts\build.py
```
- 차트 PNG(`charts.py`·`charts3d.py`) → `data.json` → `deck_v{N}.js` 순서로 실행, 출력 = `docs\발표\원자재_퀀트_MI_발표_v{N}.pptx`(이미 있으면 `_날짜-시각`을 붙여 새로 저장). 버전 생략 시 최신. 경로를 인자로 주면 그 파일로.
- 처음 한 번만 `cd docs\발표\scripts` 후 `npm install` (pptxgenjs).
- `data.json` = `nums.json` + `voltgt`(`data/voltgt_compare.csv`의 가치 혼합 · 배율 상한 4배 행: 목표·산술·복리·MDD·실현 변동성).
- 앱 화면 값을 직접 적은 장(발표일 기준으로 갱신 필요): v1 29·30번 장, v2 2·10·11번 장, v3 2·14·15번 장, v4 2·15·16번 장(요약 숫자·이번 주 판단·물량 위험 금액).
