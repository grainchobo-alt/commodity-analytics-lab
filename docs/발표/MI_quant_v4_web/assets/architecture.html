인터넷을 쓰는 경우: 자료 수집 배치, 옵션 랩 시세, AI 모델 가중치 첫 다운로드, 패키지 설치, GitHub push(사용자 승인 후), 정적 dashboard.html의 차트 라이브러리(plotly.js CDN). 화면 서버는 localhost(이 PC)에서 돕니다.

기술 스택 — 실제로 쓰는 언어·라이브러리·도구

버전은 requirements.txt, docs/발표/scripts/package-lock.json, 그리고 이 PC의 .venv에 설치된 값(importlib.metadata로 확인)입니다. 로고는 각 프로젝트의 공식 로고(공식 사이트·저장소 또는 simple-icons의 공식 브랜드 마크)를 이 파일 안에 넣었고, 공식 로고가 없거나 구하지 못한 것은 점선 텍스트 배지로 표시했습니다(가짜 로고 아님).

외부 연동 — 인터넷으로 무엇을 주고받나

사내 시스템 연동: 없음 — ERP·사내 DB·메일·메신저·사내 파일서버 접속 코드는 찾지 못함(코드의 모든 URL을 검색한 결과가 아래 표의 목록뿐). 사내 매입 이력 연동은 HANDOFF 문서에 "아이디어"로만 있음.
인증 키는 .env 파일에만 있고(값은 이 페이지에 적지 않음), 이름은 NASS_API_KEY, EIA_API_KEY, REDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET, REDDIT_USER_AGENT 5개. .gitignore로 GitHub에 올라가지 않음.
Streamlit 사용 통계 전송은 꺼져 있음 — 모든 실행 파일에 --browser.gatherUsageStats false. 화면 서버 주소(server.address)는 따로 지정하지 않아 Streamlit 기본값을 따르므로, 방화벽 설정에 따라 같은 네트워크의 다른 PC에서 접속될 수도 있음(추정 — 확인 안 됨).

데이터 저장소 — "DB"는 이 PC의 파일입니다

DB 서버(MySQL·PostgreSQL 등)는 없습니다. 표 형태 자료는 Parquet(열 단위로 압축해 저장하는 빠른 표 파일, pyarrow로 읽고 씀), 실험 결과는 CSV, 오래 걸리는 계산 결과는 pickle(.pkl)·npz(파이썬 객체·숫자 배열을 그대로 저장한 파일)로 둡니다. 크기는 2026-11-02에 이 PC에서 잰 값입니다.

파일 지도 — 폴더별 한 줄 설명

루트의 *.py가 앱과 분석 엔진, *.bat이 실행 파일입니다. .venv/(설치된 패키지), __pycache__/, .claude/·.omc/(개발 도구 설정)는 생략했습니다.
이 페이지는 한 파일로 된 정적 HTML입니다(외부 라이브러리·글꼴·CDN 없음, 로고는 파일 안에 포함). 원본: docs/architecture.html. 코드가 바뀌면 내용이 달라질 수 있으니 작성일(2026-11-04)을 기준으로 보세요.
