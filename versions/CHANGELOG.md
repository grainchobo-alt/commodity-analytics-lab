## v1.5.1 — 2026-10-19 — HMM 레짐별 회귀(BIC) · 무거래 구간
- HMM 예측 모드: 레짐별 y 평균 → 레짐별 가중 릿지 회귀(국면마다 X→y 베타가 다름), 상태 수 BIC 자동 선택(2~5, ④ 기본값). 이전엔 레짐 평균의 부호가 같으면 예측 부호가 고정돼 회전율 ≈ 0
- 무거래 구간 c (④): |예측| < c·σ̂(과거 예측)이면 직전 포지션 유지 — 모든 모델의 부호전략·walk-forward·누적 차트에 적용
- 비교 (옥수수·대두·밀, 비용 5bp, `data/hmm_band_compare.csv`): HMM 회전율 주간 ≈42·일간 ≈200으로 정상화, c=0.5가 회전율을 약 절반으로 줄여 비용 후 Sharpe 개선(일간 Kalman −0.85→−0.59, HMM −0.72→−0.37)하지만 대부분 여전히 0 이하
- walk-forward에서 HMM 자동(BIC) 상태 수는 첫 학습창에서 한 번만 선택 (매 재추정 BIC는 수십 배 느림)
- `tests/test_hmm_band.py`, 앱 테스트에 무거래 구간 경로
